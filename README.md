# StoreFeed

Mobile-first React prototype for retail transaction moments (Stories-style UI).

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal. The layout is constrained to a ~390px mobile viewport; on wider screens the feed appears centered as a phone-sized card.

## Stack

- React 19 + TypeScript
- Vite

## First screen

The Sale moment uses hardcoded mock data in `src/mockData.ts`, matching the reference design: video overlays, progress bar, Sale banner, and receipt breakdown.
